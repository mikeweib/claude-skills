# Skill 反馈模板（通用版）

当任何 skill 出现以下问题时，使用此模板记录反馈：

- 输出与预期严重不符（评分、判断、建议等）
- 某个检查规则产生系统性误判
- 报告格式或建议可操作性不足
- 技能触发时机不当（该触发未触发 / 不该触发却触发了）
- 遗漏了应该检测的问题

> **Skill 专用模板优先：** 如果 `<skill-name>/references/feedback-template.md` 存在，优先使用专用模板（它包含该 skill 特有的评估维度等字段）。

---

## 模板

### 基本信息

- **日期:** YYYY-MM-DD
- **会话 ID:** （auto-memory 的 originSessionId）
- **Skill:** <skill-name>
- **输入类型:** （该 skill 的典型输入分类，如审查类 skill 的"完整/极简/混合"）

### 错误信息

- **错误类型:** 误判 / 漏判 / 格式问题 / 建议不实用 / 触发不当 / 其他
- **涉及范围:** （skill 特有的评估维度或检查步骤，如无则填"综合"）
- **严重程度:** 高（输出失真）/ 中（一致性影响）/ 低（优化建议）

### 上下文

- **输入情况:** 提供了什么类型的内容
- **技能实际输出:** 关键输出值、扣分项、建议等（引用报告中的关键行）
- **期望输出:** 应该的输出值、扣分项、建议等

### 根因分析

- **是哪个检查规则导致了问题:** 引用 SKILL.md 的具体节/步骤
- **为什么规则在当前场景下不适用:**

### 建议修复

- **修复方式:** 修改阈值 / 补充条件 / 增加示例 / 调整措辞 / 新增规则 / 细化触发条件
- **建议变更:** 具体的文字修改建议（可选）

---

## 使用方式

1. **反馈发生时记录：** 用户发现 skill 输出有问题时，在 auto-memory 中按此格式记录
2. **skill-evolve 读取：** 运行 `skill 进化 <skill-name>` 时自动读取并按此结构解析
3. **非正式场景：** 如果只是快速反馈，可以只填写"错误信息"和"上下文"两个部分，其余由 skill-evolve 反向推断
