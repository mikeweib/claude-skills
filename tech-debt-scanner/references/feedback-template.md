# 技术债扫描反馈模板

当 `tech-debt-scanner` 技能出现以下问题时，使用此模板记录反馈：

- 评分与人工判断严重不符（偏差 > 15 分或 2 个等级）
- 某个类别产生系统性误检/漏检
- 脚本输出异常（无输出、路径错误、过滤规则失效）
- 改进建议不切实际或无法执行

---

## 模板

### 基本信息

- **日期:** YYYY-MM-DD
- **会话 ID:** （auto-memory 的 originSessionId）
- **项目类型:** C/C++ / Java / Python / JS/TS / Go / Rust / 混合
- **项目规模:** 小型(<10K行) / 中型 / 大型(>100K行)

### 错误信息

- **错误类型:** 误报 / 漏检 / 脚本异常 / 评分失真 / 改进建议不实用
- **涉及类别:** 标记注释 / 死代码 / 复杂度 / 废弃API / 重复代码 / 综合
- **严重程度:** 高（评分失真）/ 中（一致性影响）/ 低（优化建议）

### 上下文

- **输入情况:** 扫描了什么项目/目录，语言组成，大致代码量
- **技能实际输出:** 总分、等级、具体扣分项（引用报告中的关键行）
- **期望输出:** 应该的分数、等级、扣分项

### 根因分析

- **是哪个检测规则导致了问题:** 引用 SKILL.md 的 Step/节
- **为什么规则在当前场景下不适用:**

### 建议修复

- **修复方式:** 调整阈值 / 修改过滤规则 / 补充排除模式 / 修改扣分值 / 新增检测项
- **建议变更:** 具体的参数或规则修改建议（可选）
