# C++ 内存安全检查反馈模板

当 `cpp-memory-safety` 技能出现以下问题时，使用此模板记录反馈：

- 审查漏掉了内存安全问题（如 use-after-free 未检测到）
- 审查产生了误报（安全代码被标记为风险）
- Smart pointer 选择建议不符合项目实际约束
- 脚本输出异常或误匹配

---

## 模板

### 基本信息

- **日期:** YYYY-MM-DD
- **会话 ID:** （auto-memory 的 originSessionId）
- **C++ 版本:** C++14 / C++17 / C++20
- **项目类型:** 通用 / WebRTC 衍生 / Chromium 衍生

### 错误信息

- **错误类型:** 漏检 / 误报 / 脚本异常 / 建议不当
- **涉及步骤:** 裸内存操作 / 所有权配对 / Smart Pointer选择 / 类级别检查(Rule of Five) / 访问安全 / 跨函数检查
- **严重程度:** 高（安全漏洞级别）/ 中（最佳实践违反）/ 低（风格建议）

### 上下文

- **输入情况:** 审查了什么代码文件/目录，代码特征（raw pointer 多/现代 C++/WebRTC 等）
- **技能实际输出:** 报告的具体发现（引用文件:行号）
- **期望输出:** 应该报告什么或不应该报告什么

- **是哪个检查规则导致了问题:** 引用 SKILL.md 的 Step/节
- **为什么规则在当前场景下不适用:**

### 建议修复

- **修复方式:** 修改检查规则 / 调整 WebRTC 特定逻辑 / 补充 bug-patterns.md / 修改 Quick Reference
- **建议变更:** 具体的规则或参考文件修改建议（可选）
