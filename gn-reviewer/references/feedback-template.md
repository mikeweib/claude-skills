# GN 构建文件审查反馈模板

当 `gn-reviewer` 技能出现以下问题时，使用此模板记录反馈：

- 审查漏掉了重要问题（如 deps/public_deps 混淆未检测到）
- 审查产生了误报（正确写法被标记为错误）
- 脚本输出异常或路径解析错误
- 审查建议不符合 WebRTC/Chromium 项目实际规范

---

## 模板

### 基本信息

- **日期:** YYYY-MM-DD
- **会话 ID:** （auto-memory 的 originSessionId）
- **项目类型:** Chromium 衍生 / WebRTC 衍生 / 独立 GN 项目
- **文件类型:** BUILD.gn / .gni / 混合

### 错误信息

- **错误类型:** 漏检 / 误报 / 脚本异常 / 建议不当 / 路径解析错误
- **涉及步骤:** Import路径 / Target定义 / 依赖声明 / Config作用域 / 可见性 / 跨文件检查 / Flag重复 / 死代码
- **严重程度:** 高（链接错误级别）/ 中（规范违反）/ 低（风格建议）

### 上下文

- **输入情况:** 审查了什么 BUILD.gn 文件，涉及哪些 target
- **技能实际输出:** 报告的具体发现（引用文件:行号）
- **期望输出:** 应该报告什么或不应该报告什么

### 根因分析

- **是哪个检查规则导致了问题:** 引用 SKILL.md 的 Step/节
- **为什么规则在当前场景下不适用:**

### 建议修复

- **修复方式:** 修改检查规则 / 调整脚本逻辑 / 补充 WebRTC 特定规则 / 修改 Quick Reference
- **建议变更:** 具体的规则或脚本修改建议（可选）
