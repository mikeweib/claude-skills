# 系统级中断事件速查表

> **用途：** 逻辑一致性维度 Step C（场景穷举）的辅助弹药。当 PRD 涉及客户端功能时，对照此清单逐条检查 PRD 是否定义了每个系统级中断事件的行为。
>
> **使用条件：** 仅在 PRD 涉及移动端/桌面端/嵌入式设备等客户端功能时使用，纯后端/纯 Web 后台管理 PRD 可跳过。
>
> **扣分原则：** 此清单不逐条扣分——仅当 PRD 未定义的事件属于该需求的**合理风险场景**时才记录。评审者需根据 PRD 的具体业务场景判断哪些事件"必须定义"vs"可接受未定义"。

---

## 移动端（Android / iOS）

### 显示与屏幕

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| 熄屏 | ✅ | ✅ | 采集进程可能被系统挂起或杀死 | 屏幕分享/录制类需求尤其关键 |
| 亮屏 | ✅ | ✅ | 采集进程是否自动恢复？需交互还是自动？ | 恢复策略常被遗漏 |
| 屏幕旋转 | ✅ | ✅ | 采集画面方向变化 | 横竖屏切换时画面裁剪/拉伸行为 |
| 分屏/多窗口 | ✅（Android 7+） | ✅（iPadOS） | 采集区域变化、窗口焦点转移 | 单一窗口模式下分屏行为 |
| 画中画 | ✅ | ✅ | 采集层级变化 | PIP 窗口是否被采集 |
| 分辨率/刷新率切换 | ✅ | ✅（ProMotion） | 采集参数可能需要重新协商 | 游戏场景高刷↔标准刷新率切换 |
| 外接显示器 | ✅ | ✅（iPadOS） | 多屏采集源选择 | 投屏到外接显示器时采集哪块屏 |

### 音频

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| 蓝牙耳机连接/断开 | ✅ | ✅ | 音频路由切换，可能导致采集中断 | 通话/直播过程中音频设备切换 |
| 有线耳机插拔 | ✅ | — | 音频路由切换 | 同上 |
| 音频焦点被抢占 | ✅ | ✅ | 其他 App 抢占音频输出 | 语音通话/音乐播放与屏幕录制音频互斥 |
| 静音开关 | — | ✅ | iOS 硬件静音开关影响音频采集 | 录制时静音开关行为 |
| 音频会话中断 | ✅ | ✅ | Siri/语音助手打断 | 录制/推流被系统中断 |

### 通话与通知

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| 系统来电 | ✅ | ✅ | 音频中断、采集可能暂停 | VoIP 来电（微信/QQ 语音）与系统来电行为差异 |
| 闹钟/计时器 | ✅ | ✅ | 弹窗遮挡、音频打断 | 闹钟弹窗是否触发 PAUSE |
| 通知横幅 | ✅ | ✅ | 短暂遮挡内容 | 是否触发 PAUSE 还是仅视觉遮挡 |
| 勿扰模式 | ✅ | ✅ | 可能影响前台服务的通知权限 | 勿扰模式下前台服务保活策略 |
| 系统 Alert（低电量/高温） | ✅ | ✅ | 模态弹窗遮挡、可能终止后台任务 | 高温警告下系统可能强制降频/杀进程 |

### 进程与权限

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| 进程被系统杀死 | ✅ | ✅ | 低内存/省电策略终止后台进程 | 被杀后是否有状态恢复？云端残留数据如何处理？ |
| 权限被系统静默回收 | ✅（Android 11+） | ✅ | 权限自动重置导致采集失败 | 长期未使用后权限自动回收 |
| 后台限制 | ✅（各厂商差异大） | ✅ | 后台推流被限制 | 华为/小米/OPPO/vivo 后台策略各不相同 |
| 省电模式 | ✅ | ✅ | CPU/网络限制影响推流质量 | 省电模式下码率自适应策略 |
| 存储不足 | ✅ | ✅ | 本地缓存写入失败 | 录制/缓存功能的降级策略 |
| 系统升级 | ✅ | ✅ | 升级期间服务不可用、API 行为变更 | 系统大版本升级后权限模型变化 |

### 网络

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| WiFi ↔ 蜂窝切换 | ✅ | ✅ | IP 地址变更、短暂断连 | 切换时是否需要重新建立连接 |
| 网络断开/重连 | ✅ | ✅ | 推流中断 | 重连策略、断线窗口时长、重连失败最终状态 |
| VPN 连接/断开 | ✅ | ✅ | 网络路由变更 | VPN 下推流地址可达性 |
| 网络类型变更 | ✅ | ✅ | 带宽变化触发码率调整 | 5G→4G→WiFi 切换时画质自适应 |

### 其他系统事件

| 事件 | Android | iOS | 典型影响 | 常见遗漏场景 |
|------|---------|-----|---------|-------------|
| 系统录屏指示器 | ✅（Android 14+） | ✅ | 状态栏录屏图标/绿点 | 指示器弹出时是否遮挡 UI |
| 时区变更 | ✅ | ✅ | 时间戳计算偏移 | 跨国使用时推流时长统计 |
| 系统语言切换 | ✅ | ✅ | UI 文案语言变更 | App 运行中切语言，提示文案是否跟随 |
| 辅助功能（无障碍）开启 | ✅ | ✅ | TalkBack/VoiceOver 改变交互模式 | 悬浮提示条是否兼容无障碍模式 |

## 桌面端（Windows / macOS / Linux）

### 显示与窗口

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 锁屏/解锁 | 采集输出可能黑屏或静默 | 锁屏后是否继续采集/推流 |
| 显示器插拔 | 分辨率和桌面布局变化 | 多显示器环境下采集哪块屏 |
| 分辨率/缩放变更 | 采集画面尺寸变化 | 高 DPI 缩放下的采集区域计算 |
| 多显示器切换 | 窗口可能在屏幕间移动 | 采集源选择逻辑 |
| 全屏应用切换 | 全屏游戏/演示覆盖采集输出 | Alt+Tab 切换行为 |
| 远程桌面连接 | 显示会话变更 | RDP 会话下采集能力受限 |

### 音频

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 音频设备插拔 | 默认设备切换导致采集中断 | 耳机/USB 麦克风热插拔 |
| 默认音频设备变更 | 系统自动切换音频路由 | 需要在 App 内重新选择设备 |
| 音频服务重启 | Windows Audio Service 重启 | 系统更新导致的音频服务中断 |

### 进程与系统

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 休眠/睡眠 | 所有后台任务暂停 | 唤醒后是否需要恢复推流、恢复策略 |
| 系统关机/重启 | 未保存数据丢失 | 正在进行的任务如何保存状态 |
| 低电量 | 系统可能自动休眠 | 笔记本电池耗尽前是否通知用户 |
| 进程被杀（任务管理器/崩溃） | 异常退出 | 崩溃恢复、上次状态记忆 |
| 系统更新重启 | 强制关机 | 更新前是否需要保存状态 |

## Web 端（浏览器）

### 页面生命周期

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 标签页切换到后台 | 定时器降频、WebSocket 可能断连 | 后台时是否需要维持连接 |
| 标签页切回前台 | 恢复连接、UI 刷新 | 恢复后的状态同步策略 |
| 浏览器最小化 | 同标签页后台 | 后台动画/轮询是否需要暂停 |
| 页面关闭/刷新 | 未保存状态丢失 | beforeunload 是否需要拦截提示 |
| 浏览器崩溃 | 状态丢失 | 崩溃恢复机制 |

### 网络

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 离线/在线 | 网络连接状态变更 | 离线时的 UI 状态和恢复后的数据同步 |
| 网络类型变更 | 带宽变化 | 同移动端网络切换 |

### 权限与存储

| 事件 | 典型影响 | 常见遗漏场景 |
|------|---------|-------------|
| 权限被撤销 | 摄像头/麦克风/屏幕共享权限变更 | 权限撤销后是否自动停止相关功能 |
| 存储配额超限 | localStorage/IndexedDB 写入失败 | 本地缓存满时的降级策略 |
| 第三方 Cookie 策略变更 | 跨域认证失效 | 浏览器隐私策略升级的影响 |

## 评审时如何使用此清单

```
1. 确定 PRD 涉及的平台（移动端/桌面端/Web）
2. 确定 PRD 涉及的系统能力（显示采集/音频采集/网络推流/后台运行/权限管理）
3. 对照对应平台的对应分类，逐事件检查：
   a. PRD 已定义行为 → 通过
   b. PRD 未定义但属于合理风险场景 → 记录为 [状态空洞]
   c. PRD 未定义且不属于该需求的合理场景 → 跳过（如纯后台工具的 PRD 无需检查"熄屏"）
4. 在逻辑一致性维度的报告中列出发现的状态空洞
```
