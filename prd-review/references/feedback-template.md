# PRD 评审反馈模板

当 `prd-review` 技能出现以下问题时，使用此模板记录反馈：

- 评分与人工判断严重不符（偏差 > 20 分 或 2 个等级）
- 某个维度的判断规则产生系统性误判
- 报告格式或改进建议可操作性不足
- 技能触发时机不当（该触发未触发 / 不该触发却触发了）

---

## 模板

### 基本信息

- **日期:** YYYY-MM-DD
- **会话 ID:** （auto-memory 的 originSessionId）
- **PRD 类型:** 完整 / 极简 / 原型图 / 混合 / 对话

### 错误信息

- **错误类型:** 误判 / 漏判 / 格式问题 / 建议不实用 / 触发不当
- **涉及维度:** 完整性 / 清晰度 / 可行性 / 风险识别 / 可测试性 / UX 一致性 / 逻辑一致性 / 综合
- **严重程度:** 高（评分失真）/ 中（一致性影响）/ 低（优化建议）

### 上下文

- **输入情况:** 提供了什么类型的 PRD 内容
- **技能实际输出:** 评分、等级、具体扣分项（引用报告中的关键行）
- **期望输出:** 应该的评分、等级、扣分项

### 根因分析

- **是哪个检查规则导致了问题:** 引用 SKILL.md 或 review-checklist.md 的具体行/节
- **为什么规则在当前场景下不适用:**

### 建议修复

- **修复方式:** 修改阈值 / 补充条件 / 增加示例 / 调整措辞 / 新增规则
- **建议变更:** 具体的文字修改建议（可选）

---

## 使用方式

1. **反馈发生时记录：** 用户发现 prd-review 输出有问题时，在 auto-memory 中按此格式记录
2. **skill-evolve 读取：** 运行 `skill-evolve` 时会自动读取并按此结构解析
3. **非正式场景：** 如果只是快速反馈，可以只填写"错误信息"和"上下文"两个部分，其余部分由 skill-evolve 反向推断
